# Smart Hair Tool — أداة الشعر الذكية (Web, realtime)

أداة ويب واحدة (HTML + WebGL/three.js) لتصميم الشعر: استيراد شخصية أو رأس، رسم منطقة الفروة، رسم/نشر مسارات الشعر الأولية (Guides)، تمشيطها بفرشاة، ثم توليد **Hair Cards** فورياً بنسيج Alpha وShader شعر (Kajiya‑Kay مزدوج) — بدون Maya أو Blender أو ZBrush.

## التشغيل
افتح `index.html` مباشرة في Chrome/Edge/Firefox (لا يحتاج خادماً). إعادة البناء بعد تعديل `src/`:

```
npm install && npm run build   # يحتاج bun
```

## مثال البورتريه
يُفتح افتراضياً (زر «مثال البورتريه»): موديل `MaleHead.obj` بعد تنعيمه (Loop subdivision) مع تسريحة مطابقة لصورة المرجع — شعر داكن مموج مرفوع للخلف بحجم وخصلات شاردة، أذنان مكشوفتان، حواجب كثيفة مقطّبة، شارب كثيف، وظل لحية. الإعدادات في `src/portrait.js` (خط الشعر، اتجاهات التسريح، الألوان).

## سير العمل
1. **استيراد** موديل GLB/OBJ (أو اسحبه وأفلته)، أو استخدم الرأس الافتراضي.
2. **رسم منطقة الفروة** (M) ثم «توليد من المنطقة» — تُولَّد مسارات تتدفق من الدوامة (Crown) للأسفل.
3. **رسم مسار** (D): يمكن مواصلة الرسم في الهواء لتحديد انسدال الشعر. **فرشاة إضافة** (A) تنشر مسارات باتجاه السحب.
4. **تمشيط / تنعيم / طول / رفع / حذف** (C S L P E) بتناظر X وبحفاظ على أطوال المسارات وتصادم مع الموديل.
5. **البطاقات**: النوع من الأطلس، العرض، التعبئة بين المسارات، الالتواء، الخصلات الشاردة… كلها فورية.
6. **الخامة والإضاءة**: تدرج جذر→طرف، لمعتان، SSS، AO، شمس/ظل/داخلي. **فيزياء**: معاينة رياح وهز رأس.
7. **تصدير**: بطاقات GLB/OBJ، منحنيات OBJ (Guide Curves)، لقطة PNG، حفظ/فتح مشروع JSON.

اختصارات: `[` `]` حجم الفرشاة · `Ctrl+Z` / `Ctrl+Shift+Z` · Shift يعكس عمل الطول/الرفع/القناع · تدوير: كليك أيمن أو Alt+سحب.
